==================================================
CACHING
==================================================

Do not fetch external APIs on every page load.

Use PostgreSQL caching.

Flow:

Request
↓
Check cache
↓
Cache valid?
YES → return cached data

NO
↓
fetch external data
↓
validate
↓
store cache
↓
return data

Define reasonable TTLs per provider.

Handle stale cache gracefully.

If external API is temporarily unavailable and stale cache exists:

return stale data with a stale indicator.

If no cache exists:

return an appropriate unavailable state.
