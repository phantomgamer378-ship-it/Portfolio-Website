# Design System Foundation

## Concept
"DARK TECHNICAL EDITORIAL × INTERACTIVE SYSTEMS"

## Tokens (defined in index.css)
- **Background:** Deep near-black (`#0a0a0a`)
- **Typography:** Off-white (`#f4f4f5`)
- **Accent:** Restrained cyan/blue-violet (`#6366f1`)
- **Display Font:** Space Grotesk
- **Technical Font:** JetBrains Mono

## Avoid
- Generic hacker terminal aesthetics
- Excessive green neon or particles
- Fake 3D or skill percentages
